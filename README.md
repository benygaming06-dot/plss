# KURT DHYLAN MOTO SHOP INVENTORY V2

Offline Android inventory app for a motorcycle shop.

## Functions
- Add Product: Name, Brand, Model, Price, Stocks
- Search Products
- Edit/Delete Products
- Add Service/Labor: Name and Price
- Search Services
- Edit/Delete Services
- Dashboard counts
- Local offline JSON storage using SharedPreferences
- Cart placeholder with saved local cart support
- Red/black racing UI
- New KURT DHYLAN app icon
- Android 15 target (API 35)
- GitHub Actions debug APK build

## Build
Run the GitHub Actions workflow **Build Kurt MotoShop APK**, then download the APK artifact.
